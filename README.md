## 수정

이 저장소의 HTML을 직접 고치지 않습니다. 원본과 빌드 도구는 로컬 작업 폴더에 있습니다.

```
경력기록 모음/2_기본문서/web/
  오경식-포트폴리오.body.html
  오경식-경력기술서.body.html
  _style.css
  build.sh          → 로컬 HTML + 제출용 PDF
  publish-web.py    → 이 저장소용 공개판 (전화번호 제외)
```
